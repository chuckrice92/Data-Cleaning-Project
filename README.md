# Data Cleaning with Python

## Project Overview

This project focuses on cleaning a customer credit and spending dataset using **Python and pandas** in a Jupyter Notebook.

The original dataset contains common data-quality issues such as missing values, incorrect data types, inconsistent categories, invalid values, and formatting issues.

## Dataset

The dataset was obtained from Kaggle:

**Customer Credit & Spending Dataset (Dirty)**
[Kaggle Dataset](https://www.kaggle.com/datasets/aramelheni/dirty-dataset?utm_source=chatgpt.com)

The dataset contains customer information such as:

* Age
* Income
* Education
* Credit Score
* Loan Amount
* Employment Years
* Default Status
* Product Type
* Purchase Frequency
* Monthly Spending
* Location
* Account Dates

## Tools Used

* Python
* Jupyter Notebook
* pandas

## Data Cleaning

The following cleaning tasks were performed:

* Checked the dataset structure and data types
* Identified and handled missing values
* Checked for duplicate records
* Converted columns to appropriate data types
* Corrected invalid ages and employment years
* Standardized categorical values
* Cleaned phone numbers and ZIP codes
* Checked email formatting
* Converted date columns to datetime
* Identified invalid spending values

## Result

The cleaned dataset is prepared for further **exploratory data analysis and visualization**.
